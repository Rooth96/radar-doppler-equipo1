# Registro de uso de Inteligencia Artificial

Esta carpeta contiene el registro trazable del uso de herramientas de inteligencia artificial durante el desarrollo del proyecto.

Por cada interacción relevante se debe registrar:

- Fecha.
- Integrante responsable.
- Herramienta utilizada.
- Prompt o resumen fiel del prompt.
- Resultado utilizado.
- Resultado descartado, si corresponde.
- Forma en que el resultado fue verificado.
